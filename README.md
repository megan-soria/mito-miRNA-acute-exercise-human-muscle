# Mitochondrial miRNA Profiling in Human Skeletal Muscle Following Acute Exercise

This repository contains the analysis code and supporting files for the manuscript:

“Mitochondria isolated from human male skeletal muscle contain a distinct population of miRNA that are differentially expressed following acute exercise.”

### Study Overview

MicroRNAs (miRNAs) are traditionally considered cytosolic regulators of gene expression; however, emerging evidence suggests that they also localise within mitochondria. This study used small RNA sequencing to characterise and compare the miRNA population in:

- Whole skeletal muscle tissue

- skeletal muscle mitochondria

from healthy male participants at:

- Rest

- Immediately post-exercise

- 3 hours post-exercise

Participants completed 60 minutes of cycling at 70% VO₂peak.
